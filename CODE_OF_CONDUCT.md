# Código de Conduta

## Nosso compromisso

Participar deste projeto deve ser uma experiência livre de assédio para todos,
independentemente de idade, corpo, deficiência, etnia, identidade e expressão de gênero,
experiência, nacionalidade, aparência, raça, religião ou orientação sexual.

## Nossos padrões

Comportamentos que contribuem para um ambiente positivo: linguagem acolhedora,
respeito a pontos de vista diferentes, aceitar críticas construtivas, focar no que é
melhor para a comunidade. Inaceitáveis: linguagem ou imagens sexualizadas, ataques
pessoais, assédio, publicar informação privada de terceiros.

## Aplicação

Relatos de abuso podem ser enviados para maxwellmezadre@gmail.com. Todas as denúncias
serão analisadas com confidencialidade.
